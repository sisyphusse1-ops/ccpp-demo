# ccpp-demo

Demo repo showing the one-two punch of [claude-code-pro-pack](https://github.com/sisyphusse1-ops/claude-code-pro-pack) + [cc-audit](https://github.com/sisyphusse1-ops/cc-audit) via GitHub Actions.

- Install the pack at setup
- Lint on every PR
- Fail the build on leaked secrets

See `.github/workflows/` for the wiring. Look at the Actions tab for real runs.
